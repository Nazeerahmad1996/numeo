# Numeo
Real-time voice translation app that captures audio from the browser, streams it to a Node.js backend via WebSockets, and uses Ollama for instant translation.

## Requirements
* **Node.js**: v18 or higher
* **Ollama**: Must be installed and running locally
* **Model**: `qwen2.5-coder:1.5b` (configurable in BE config)

## Setup
1. `npm install`

## Run
1. `npm run dev`

Starts the client and backend concurrently.
